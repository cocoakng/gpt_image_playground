AI-Link.shop 生图 API

兼容 OpenAI Images API 官方参数规范

在线可用 OpenAI Images API 兼容
参数来源说明：本文档仅收录 OpenAI 官方 参数。 项目自定义 参数（如 stream、partial_images、quality: "auto" 等）已被剔除。 若你使用的是 OpenAI 官方接口或其他标准兼容接口，可直接按此文档对接。

接口概览

POST
/images/generations
根据文本提示生成图片（文生图），每次请求仅返回一张
POST
/images/edits
基于参考图进行编辑或局部重绘（图生图），每次请求仅返回一张

认证方式

所有接口需在 HTTP Header 中携带 Authorization 进行 Bearer Token 认证。

Authorization: Bearer <YOUR_API_KEY>

文生图

根据文本提示生成一张图片。

单次单图：每次请求仅生成并返回一张图片。如需多张，请发起多次独立请求。
POST /images/generations

请求参数

参数类型必填官方取值说明
model string 是 gpt-image-2, gpt-image-1, dall-e-3, dall-e-2 模型 ID
prompt string 是 自然语言文本 图片描述提示词。gpt-image-2 最长 32000 字符
size string 否
gpt-image-2 任意满足约束的分辨率 （见下方尺寸约束）
gpt-image-1 1024x1024, 1024x1536, 1536x1024, auto
dall-e-3 1024x1024, 1792x1024, 1024x1792
dall-e-2 256x256, 512x512, 1024x1024
 输出尺寸。默认因模型而异
quality string 否
gpt-image-2 low, medium, high
dall-e-3 standard, hd
 图片质量。默认因模型而异
output_format string 否 png, jpeg, webp gpt-image-1/2 输出格式。默认 png
output_compression integer 否 0 ~ 100 gpt-image-1/2 压缩率。仅对 jpeg / webp 有效
moderation string 否 auto, low gpt-image-1/2 内容审核严格程度。默认 auto
background string 否 transparent, opaque, auto gpt-image-1/2 背景模式。默认 auto
response_format string 否 url, b64_json 返回格式。默认 url
user string 否 任意字符串 终端用户唯一标识，用于滥用检测
style string 否 vivid, natural dall-e-3 only 图像风格。默认 vivid
gpt-image-2 尺寸约束（官方）：最大边 < 3840px；两边均为 16 的倍数；长宽比 ≤ 3:1；总像素在 655,360 ~ 8,294,400 之间。超过 2560×1440 视为实验性分辨率。

请求示例

curl -s https://www.ai-link.shop/v1/images/generations \

  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一只在月光下看书的橘猫，卡通风格",
    "size": "1024x1536",
    "quality": "high",
    "output_format": "png",
    "moderation": "auto",
    "response_format": "b64_json"
  }'

图生图 / 编辑

基于参考图片进行编辑或局部重绘。支持上传参考图和遮罩图。

POST /images/edits
此接口使用 multipart/form-data 格式提交。输入图片大小必须小于 50MB，格式为 PNG 或 JPG。
单次单图：每次请求仅生成并返回一张图片。如需多张，请发起多次独立请求。

请求参数

参数类型必填官方取值说明
image file 是 PNG / JPG，< 50MB 待编辑的参考图片。gpt-image-2 支持 PNG/JPG
mask file 否 PNG，与参考图同尺寸 遮罩图片。透明/白色区域表示需编辑区域，黑色表示保留
model string 是 gpt-image-2, gpt-image-1, dall-e-2 模型 ID
prompt string 是 自然语言文本 编辑指令提示词
size string 否 同文生图尺寸取值 输出尺寸
quality string 否 low, medium, high gpt-image-1/2 图片质量
output_format string 否 png, jpeg, webp gpt-image-1/2 输出格式。默认 png
output_compression integer 否 0 ~ 100 gpt-image-1/2 压缩率。仅 jpeg/webp 有效
moderation string 否 auto, low gpt-image-1/2 内容审核级别。默认 auto
background string 否 transparent, opaque, auto gpt-image-1/2 背景模式。默认 auto
response_format string 否 url, b64_json 返回格式。默认 url
user string 否 任意字符串 终端用户标识

请求示例（curl）

curl -s https://www.ai-link.shop/v1/images/edits \
  -H "Authorization: Bearer <YOUR_API_KEY>" \
  -F "model=gpt-image-2" \
  -F "prompt=把背景换成星空" \
  -F "size=1024x1024" \
  -F "output_format=png" \
  -F "image=@cat.png" \
  -F "mask=@mask.png"

Python 请求示例

import requests

url = "https://www.ai-link.shop/v1/images/edits"
headers = {"Authorization": "Bearer <YOUR_API_KEY>"}
data = {
    "model": "gpt-image-2",
    "prompt": "把背景换成星空",
    "size": "1024x1024",
}
files = [
    ("image", ("cat.png", open("cat.png", "rb"), "image/png")),
    ("mask", ("mask.png", open("mask.png", "rb"), "image/png")),
]

resp = requests.post(url, headers=headers, data=data, files=files)
print(resp.json())

关于返回格式：默认返回 url（临时链接，会过期），建议生产环境立即下载转存；若指定 response_format: "b64_json"，则直接返回 Base64 编码数据。

常用尺寸比例适用场景

错误码

接口遵循标准 HTTP 状态码规范，失败时返回对应的状态码和错误详情。

状态码含义常见原因
200成功请求正常处理，返回图片数据
400请求参数错误缺少必填参数、参数格式不合法、prompt 为空
401未授权API Key 无效、缺失或已过期
403内容策略拦截提示词触发安全过滤、生成内容被拦截
429请求过于频繁超出速率限制，需降低请求频率
500服务器内部错误模型服务端异常，建议稍后重试
504网关超时生成耗时过长（高质量请求可达 15~30 秒），建议增加超时时间或异步处理

错误响应格式

HTTP/1.1 401 Unauthorized
Content-Type: application/json

{
  "error": {
    "message": "Invalid authentication credentials",
    "type": "authentication_error",
    "code": "invalid_api_key"
  }
}

完整 SDK 示例（Python）

以下脚本封装了文生图和图编辑的完整调用流程，可直接保存运行。

import argparse
import base64
import json
import sys
from pathlib import Path
from typing import List, Optional

try:
    import requests
except ImportError:
    print("请先安装 requests: pip install requests")
    sys.exit(1)

BASE_URL = "https://www.ai-link.shop/v1"
DEFAULT_MODEL = "gpt-image-2"

def generate(api_key: str, model: str, prompt: str, **kwargs) -> dict:
    url = f"{BASE_URL}/images/generations"
    payload = {
        "model": model,
        "prompt": prompt,
        "size": kwargs.get("size", "1024x1536"),
        "quality": kwargs.get("quality", "high"),
        "output_format": kwargs.get("format", "png"),
        "moderation": kwargs.get("moderation", "auto"),
        "response_format": "b64_json",
    }
    if kwargs.get("compression") is not None:
        payload["output_compression"] = kwargs["compression"]
    resp = requests.post(
        url, headers={"Authorization": f"Bearer {api_key}"},
        json=payload, timeout=300
    )
    resp.raise_for_status()
    return resp.json()

def edit(api_key: str, model: str, prompt: str,
         image_paths: List[str], mask_path: Optional[str] = None, **kwargs) -> dict:
    url = f"{BASE_URL}/images/edits"
    data = {
        "model": model,
        "prompt": prompt,
        "size": kwargs.get("size", "1024x1024"),
        "output_format": kwargs.get("format", "png"),
    }
    files = []
    handles = []
    try:
        for p in image_paths:
            path = Path(p)
            f = open(path, "rb")
            handles.append(f)
            mime = f"image/{path.suffix.lstrip('.')}" if path.suffix else "image/png"
            files.append(("image", (path.name, f, mime)))
        if mask_path:
            f = open(mask_path, "rb")
            handles.append(f)
            files.append(("mask", ("mask.png", f, "image/png")))
        resp = requests.post(
            url, headers={"Authorization": f"Bearer {api_key}"},
            data=data, files=files, timeout=300
        )
        resp.raise_for_status()
        return resp.json()
    finally:
        for f in handles: f.close()

def save_images(response: dict, prefix: str = "output") -> List[str]:
    saved = []
    for i, item in enumerate(response.get("data", [])):
        b64 = item.get("b64_json")
        url = item.get("url")
        if b64:
            img_data = base64.b64decode(b64)
        elif url:
            img_data = requests.get(url, timeout=60).content
        else:
            continue
        ext = item.get("output_format", "png")
        path = f"{prefix}_{i+1}.{ext}"
        Path(path).write_bytes(img_data)
        saved.append(path)
        print(f"已保存: {path}")
    return saved

if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("--key", required=True)
    parser.add_argument("--model", default=DEFAULT_MODEL)
    parser.add_argument("--prompt", required=True)
    parser.add_argument("--mode", choices=["generate", "edit"], default="generate")
    parser.add_argument("--image", nargs="+")
    parser.add_argument("--mask")
    parser.add_argument("--size", default="1024x1536")
    parser.add_argument("--quality", default="high")
    parser.add_argument("--format", default="png")
    parser.add_argument("--compression", type=int)
    parser.add_argument("--out", default="output")
    args = parser.parse_args()
    kwargs = {"size": args.size, "quality": args.quality,
                "format": args.format, "compression": args.compression}
    if args.mode == "generate":
        resp = generate(args.key, args.model, args.prompt, **kwargs)
    else:
        if not args.image: parser.error("edit 模式需要 --image")
        resp = edit(args.key, args.model, args.prompt, args.image, args.mask, **kwargs)
    print(json.dumps(resp, indent=2, ensure_ascii=False))
    save_images(resp, prefix=args.out)
